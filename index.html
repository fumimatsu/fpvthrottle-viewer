Upload an MP4 video, select the on-screen number area, and generate a throttle timeline graph.

Load a video to begin.

How to use

  1. Load an MP4 video that displays a numeric throttle indicator.
  2. Pause the video on a frame that clearly shows the number. Use the mode toggle to switch between video controls and drawing, then drag on the video to outline the number region.
  3. (Optional) Adjust the OCR engine, frame interval, or expected value range to fit your data (e.g., voltage readings).
  4. Adjust the frame interval if needed, then click Analyze to extract throttle values frame by frame.

The recognized values (0-100) will appear in a line chart and table below. You can download the results as CSV.
